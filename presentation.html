⚠️ Problem Statement

Citizens are left out of welfare they deserve

Millions of eligible citizens — especially from rural and marginalized communities — never benefit from government welfare programs because scheme information is fragmented, dense, and inaccessible. A citizen must manually cross-reference their demographics (income, caste, gender, occupation, state) against hundreds of overlapping eligibility criteria spread across departmental portals.

The core challenge: information asymmetry caused by bureaucratic language, fragmented portals, and zero personalization.

📄 Abstract

What we built

We present the Government Scheme Discovery & Eligibility Assistant — a hybrid multi-agent AI application that eliminates information asymmetry in public welfare distribution. The system accepts plain-language or voice queries, extracts a structured demographic profile using Gemini 2.5 Flash, and runs a dual-engine retrieval pipeline: a local RAG vector store over 100+ master schemes (ChromaDB + Sentence Transformers) and a live fallback via Playwright DOM scraping + Serper API Google Search. A policy adjudicator agent then evaluates eligibility rules, generates ineligibility notices for disqualified schemes, and the counselor agent produces step-by-step application guides — all delivered in 10+ Indian regional languages via an interactive React.js dashboard.

myscheme.gov.in is a Next.js SPA — Playwright Headless Chromium renders JS before DOM extraction.

📉

Challenge: Low-Confidence RAG

Cosine similarity threshold (≥0.70) triggers automatic fallback to live web search to prevent hallucinations.

Key Features & Modules

1

Conversational Profile Builder

  • Natural language input (text or voice mic)
  • Gemini extracts structured JSON profile
  • Clarification loop for missing fields
  • Supports 10+ Indian regional languages
2

Dual-Engine Scheme Retrieval

  • Primary: ChromaDB vector similarity ≥ 0.70
  • Fallback: Playwright scrapes myscheme.gov.in
  • Live Google Search via Serper API (site:gov.in)
  • Covers 500+ central & state schemes
3

LLM Policy Adjudicator

  • Gemini 2.5 Flash evaluates eligibility rules
  • Checks age, income, caste, gender bounds
  • ⚠️ Explicit ineligibility notice cards rendered
  • Match score & confidence shown per scheme
4

Guidance & Accessibility

  • Step-by-step application roadmaps
  • Document checklists per scheme
  • Clickable official portal links
  • TTS voice playback for low-literacy users
